# Social Poster

Social media content planner and automatic publisher.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Supabase PostgreSQL + Storage
- Node.js + TypeScript publisher
- GitHub Actions

## Current state

The original planner UI is preserved in `reference/Social Planner.html`.
The React app is the migration target. Supabase and platform APIs are not
connected yet.

## Planned publishing platforms

- Facebook
- YouTube
- Threads
- Instagram

Never put platform secrets or the Supabase service-role key in the frontend.
